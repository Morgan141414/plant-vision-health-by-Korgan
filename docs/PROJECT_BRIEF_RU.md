# PlantVision AI: краткое описание проекта

PlantVision AI — исследовательский проект локального компьютерного зрения для наблюдения за городской растительностью по материалам БПЛА и наземных камер. Он предназначен для подготовки предварительных карточек наблюдения и передачи результатов во внешнюю систему.

## Текущая версия

В репозитории реализованы FastAPI-сервис, веб-интерфейс загрузки фото, наблюдение растительного покрова, REST API и WebSocket для JPEG-кадров. Также предусмотрен адаптер локальной TorchScript-модели определения вида.

Без установленной и валидированной модели сервис возвращает `unavailable` для вида растения и `REQUIRES_REVIEW` для состояния. Такой ответ означает, что система не делает неподтверждённых биологических выводов.

## План развития

1. Собрать и экспертно разметить не менее 3 000 кадров в COCO с ракурсами сверху и с земли.
2. Обучить сегментацию органов растения и отдельные модели вида и визуальных признаков состояния.
3. Экспортировать модели в Core ML или ONNX, измерить память и задержку на Apple Silicon M4.
4. Провести независимую валидацию метрик до включения статусов `Healthy`, `Water Stress`, `Diseased` и `Critical`.

## Важное ограничение

Целевые показатели точности и 60 FPS из технического задания являются критериями приёмки, а не подтверждёнными характеристиками текущего прототипа. Результат системы не заменяет очный осмотр дендролога или фитопатолога.
